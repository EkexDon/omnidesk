This repository hosts the OmniDesk Hub website (GitHub Pages) and its release downloads.
The app is free to download and use; its source code is not public.

**Requirements:** a Mac with Apple silicon (M1 or later) and macOS 13 Ventura or later, or a PC with Windows 10/11 (x64 or ARM — the ARM installer is `OmniDesk-Hub-win-arm64.exe`).
**First launch:** the app isn't signed by Apple or Microsoft yet. On a Mac use *Open Anyway* in Privacy & Security; on Windows click *More info → Run anyway*. Details on the website and in the release notes.
